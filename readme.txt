1. Откройте командную строку (Поиск -> cmd -> Командная строка).
2. Перейдите в репозиторий, где вы планируете работать (cd Имя_папки - перейти вниз, cd .. - перейти вверх).
3. Склонируйте репозиторий командой git clone урл/вашего.репозитория.
4. Перейдите в репозиторий (cd 25812, если вы его не переименовали).
5. Отколите ветку и перейдите на нее (git checkout -b mybranch (имя можно поменять))).
6. Внесите изменения в файл. Можете использовать любой редактор кода.
   Для просмотра можно просто открыть файл двойным нажатием, и он откроется в браузере по умолчанию.
7. Проверьте статус репозитория командой git status
8. Добавьте изменения в коммит командой "git add .".
9. Добавьте коммит git commit -m "Я поменял...".
10.Запушьте изменения в мэйн.
11. САМОЕ СЛОЖНОЕ. В таблицу на гугл-диске "Задания" в строку вашей фамилии в столбец C (Git+HTML) вставьте урл вида: https://html-preview.github.io/?url=<урл файла в вашем форке>.
    Например, у меня это https://html-preview.github.io/?url=https://github.com/Avazork/25812/blob/main/zagotovka.html.
    Я посмотрю и проверю.)
